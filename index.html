Madisonville Local Area WebGIS

Interactive Mapping | Leaflet.js | Madisonville, Kentucky

Project Overview

This interactive WebGIS application demonstrates local area mapping in Madisonville, Kentucky using Leaflet, JavaScript, HTML, and CSS.

Explore sample point locations, a connecting line, and a demonstration study area using multiple basemaps.

Map Features

  • Interactive point features
  • Clickable feature popups
  • Sample connecting route
  • Demonstration study area
  • Three Esri basemaps
  • Layer visibility controls

Map Legend

Point Locations
Sample Route
Study Area

Map Navigation

Use the layer control in the upper-right corner to switch basemaps and show or hide features.

Live Map Coordinates

Move your mouse over the map to display latitude and longitude.
